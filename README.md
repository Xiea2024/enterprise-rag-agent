# Enterprise RAG Agent

An enterprise-oriented RAG and AI Agent backend built with Python and FastAPI.

The project aims to provide document ingestion, retrieval-augmented
generation, source-grounded question answering and extensible agent
orchestration.

## Status

🚧 Under active development.

Current milestone: V0.1 - Backend foundation.

## Planned Features

- Document ingestion
- Text chunking
- Embedding
- Vector retrieval
- Reranking
- RAG question answering
- Source citation
- Agent abstraction
- Multi-agent orchestration

## Tech Stack

- Python
- FastAPI
- Pydantic
- Qdrant
- Docker
- pytest
